# Project1 Design System

This is a starter DESIGN.md. It gives coding agents a persistent, structured
understanding of the product's visual design system: the machine-readable tokens
in the YAML front matter above, and the human-readable rationale below.

## Color

`primary` is a near-black ink used for text and primary surfaces. `secondary` is
a muted gray for supporting text. `accent` is a warm terracotta reserved for
calls to action and highlights, used sparingly to preserve its emphasis.
`background` is the page base and `surface` is a subtle raised panel tone.

## Typography

Public Sans carries the whole system. `h1` is tight and confident for page
titles; `body` prioritizes readability with a generous 1.6 line height.

## Spacing & Radius

Spacing follows a 4px base scale from `xs` to `xl`. Corner radii range from a
subtle `sm` to a fully rounded `full` for pills and avatars.
